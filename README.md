# Xanther Context Engine (XCE)

Graph RAG context retrieval system for coding agents. Parses code repositories, builds a knowledge graph, and serves architectural context via MCP.

## Related Work

- [Matching Frontier Code Agents with Lightweight Models via Multi-Model Consultation](https://www.qeios.com/read/QG4N5O) — Ghanta & Paladugu (2026). Demonstrates Claude Haiku 4.5 matching Opus-level performance (74.6% on SWE-bench Verified) via multi-model consultation through MCP. DOI: [10.32388/QG4N5O](https://doi.org/10.32388/QG4N5O)
